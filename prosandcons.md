# Pros and Cons Prompting

This is a strategy whereby you use AI to find out the best means of implement a codeblock, function, feature or basically system design patterns best for your project. 

## example:

"what are a few different ways that I can implement this db connection logic. give me the pros and cons for each strategy. #file:db.ts"

### follow up prompting 
## example:

"rewrite the code as a singleton #file:dbts"

## example:
